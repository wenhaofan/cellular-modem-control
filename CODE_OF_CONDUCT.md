# Code of Conduct

This project aims to be a practical and respectful engineering space.

## Expected Behavior

- Be direct and constructive.
- Assume contributors may be testing on different hardware, carriers, and
  operating systems.
- Keep discussions focused on reproducible behavior, command traces, logs with
  sensitive values redacted, and maintainable fixes.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Posting private phone numbers, SIM identifiers, IMEI values, SMS contents, or
  carrier account data without consent.
- Pressuring contributors to run billable or destructive modem actions.

Maintainers may edit, hide, or remove comments and contributions that violate
these rules.
